# Ch27｜项目三：多 Agent 研究助手

> **本章目标**：从 0 搭建一个由 4 个 Agent 协作的研究助手，自动完成"选题 → 调研 → 写作 → 审核"。

## 27.1 项目目标

构建一个 4 Agent 协作系统：

```mermaid
graph LR
    User --> Coord[Coordinator]
    Coord --> R[Researcher]
    Coord --> W[Writer]
    Coord --> E[Editor]
    R --> W
    W --> E
    E --> Coord
```

**4 个 Agent**：

- **Researcher**：搜索资料、整理文献
- **Writer**：基于资料撰写文章
- **Editor**：审核、修改、润色
- **Coordinator**：协调三者
