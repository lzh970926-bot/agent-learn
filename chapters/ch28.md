# Ch28｜项目四：生产级 LLM 网关

> **本章目标**：从 0 搭建一个支持 10+ 模型、多租户配额、语义缓存、全链路可观测的 LLM 网关。

## 28.1 项目目标

构建一个 OpenAI 兼容的 LLM API Gateway：

- ✅ 多模型路由（OpenAI / Anthropic / 本地）
- ✅ 多租户配额
- ✅ 语义缓存
- ✅ 灰度发布
- ✅ 全链路可观测

## 28.2 技术栈

| 组件 | 选型 |
|---|---|
| HTTP | FastAPI |
| 缓存 | Redis + Qdrant（语义） |
| 限流 | Redis Token Bucket |
| 审计 | PostgreSQL |
| 追踪 | OpenTelemetry + Langfuse |

## 28.3 完整架构

```mermaid
graph TB
    Client --> Auth
    Auth --> RL[Rate Limit]
    RL --> Cache
    Cache -->|miss| Router
    Router --> Adapter
    Adapter --> Provider
    Provider --> Adapter
    Adapter --> Cost
    Cost --> Response
    Response --> Cache
```
