# 《大模型 Agent 系统开发：从原理到架构》

## 书籍定位

一本面向**中高级 Python 工程师**的 Agent 系统开发实战书。目标读者具备 Web 后端开发经验，希望系统掌握 LLM Agent 的**设计原理、框架内核、工程架构**三项能力，最终能独立设计生产级 Agent 系统。

## 核心特色

- **深入浅出**：从"为什么"出发，再讲"怎么做"，避免 API 手册式罗列
- **源码解读**：关键抽象直接读 LangChain / LangGraph / LlamaIndex 源码，理解设计权衡
- **架构视角**：不局限于单个框架，培养"框架选型 + 系统设计"的能力
- **实战驱动**：每章配可运行示例，末尾有综合项目

## 读者画像

| 维度 | 期望水平 |
|---|---|
| Python | 中级（熟悉 async、类型提示、包管理） |
| Web 开发 | 2+ 年（理解 REST、消息队列、数据库） |
| LLM 基础 | 听过 OpenAI API，用过 LangChain 写 Demo |
| 分布式 | 了解基本概念（缓存、限流、可观测性） |
